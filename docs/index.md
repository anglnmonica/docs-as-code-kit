# Get started with the docs kit

This page is an example. Replace it with your own docs, or change
`repository.content_path` in `docs-kit.yml` to point at the folder where
your docs already live.

## Check this page

Every pull request runs the checks turned on in `docs-kit.yml`. To see a
check fail, misspell a word on this page, such as "receive" with the "e" and
"i" swapped, and open a pull request. The spelling check flags it.

## Next steps

1. Fill in the `project` section of `docs-kit.yml` with your product name and readers.
2. Turn on any domain packs that match your product.
3. Open a pull request and review the results on the **Checks** tab.
